\# Kubernetes Experiment 1



\## Title

Build a Multi-Node Kubernetes Cluster Using kind.



\## Objective

To create a 3-node Kubernetes cluster using kind,

identify control-plane components, deploy nginx,

scale Pods, expose the application and test self-healing.



\## Technologies Used

\- Docker Desktop

\- Kubernetes

\- kind

\- kubectl

\- Windows PowerShell

\- Nginx



\## Files

\- kind-3node.yaml

\- experiment1-commands.md

\- screenshots/



\## Result

Successfully created a 3-node Kubernetes cluster,

deployed nginx, tested self-healing, scaled replicas

and accessed the application through localhost:8080.
